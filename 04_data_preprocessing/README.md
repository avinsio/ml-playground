# Data Preprocessing

This folder contains my notes, practice notebooks, experiments, and exercises while learning **Feature Engineering**. It focuses on preparing and transforming data for machine learning.

---

## Overview

This folder covers techniques used to transform raw data into useful features for machine learning models. Topics include handling missing values, encoding categorical variables, scaling numerical features, creating new features, and selecting useful features.
